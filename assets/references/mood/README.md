# Concept and mood references

Use only the relevant subset: `characters/` for identity/palette/poses, `world/` for theme/composition, `ui/` for frames and overlays, and `ui/flow/` for screen-flow studies. Start with [the current baseline](../current-approved/README.md) for actual scale and rendering.

These are directional concepts, not runtime atlases, exact collision maps, final UI text/counts or rules. The town image is an environment reference, not a Thiên Sơn/Thiếu Lâm character sheet. Existing concept approval does not grant final in-game approval or establish third-party rights.
