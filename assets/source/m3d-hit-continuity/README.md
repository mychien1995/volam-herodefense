# M3D hit impact

`impact.aseprite` has separate spark and fracture tags. The runtime atlas retains the approved 112 × 112 cels and the centered pivot. The 110 ms spark and 210 ms fracture run independently in the match renderer.

The spark was color-graded from the four Metal Contact cels in the arena creep impacts. The small ground fracture was cropped and color-graded from Hoàn Nhan Hồng Liệt’s stomp. `preview-provenance.json` records hashes for the source atlases used in the review. `assets/approved_m3d_hit_continuity.lock.json` pins the editable source and runtime export.
